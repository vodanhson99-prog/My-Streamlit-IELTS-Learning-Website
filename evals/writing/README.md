# IELTS Writing Grader Evaluation Benchmark

Labelled offline evaluation harness for measuring IELTS grader accuracy against verified benchmarks.

## Usage

```bash
pnpm eval:writing
```

## Metrics Reported
- **MAE** (Mean Absolute Error)
- **Within ±0.5 Band %**
- **Exact Match %**
- **Over/Undergrading counts**
